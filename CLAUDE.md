## Next.js 16 — breaking changes from prior versions

Per `frontend/AGENTS.md`, this is **Next.js 16**, which has breaking changes in APIs, conventions, and file structure that likely differ from training data. Before writing Next.js code (routing, data fetching, caching, server components, config), consult the local docs at `frontend/node_modules/next/dist/docs/` (resolved from the file's directory, not the repo root). Heed any deprecation notices there.

## Architecture notes

- **App Router only** — code lives in `frontend/src/app/`. Path alias `@/*` → `./src/*` (see `tsconfig.json`).
- **Tailwind CSS v4** is wired through Turbopack (not PostCSS). `next.config.ts` registers `@tailwindcss/turbopack` as the loader for `*.css`. Global styles live in `src/app/globals.css`.
- **Experimental flags enabled in `next.config.ts`:** `cacheComponents: true` and `partialPrefetching: true`. Changes to caching/prefetching behavior should assume these are on — check the local docs before overriding or relying on default behavior.
- **React 19.3** with the new `jsx: "react-jsx"` transform; `strict: true` in `tsconfig.json`.
- Root layout uses the `LayoutProps<"/">` generic (a Next 16 convention) rather than a manually typed `children` prop — follow this pattern in other layouts.
